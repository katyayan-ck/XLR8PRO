2. CATEGORY 1: PSR-4 VIOLATIONS & CLASS/FILENAME INCONSISTENCIES
================================================================================

1. [CRITICAL] app/Services/AuthService.php
   - Problem: Filename is AuthService.php, but declared class is `class AiGatewayService`.
   - Impact: Calling `App\Services\AuthService` throws ClassNotFoundException.
   - Fix: Move `AiGatewayService` to `app/Services/AiGatewayService.php`. Restore canonical `AuthService` handling OTP/Sanctum authentication per .clinerules §7.2.

2. [CRITICAL] app/Http/Controllers/Api/V1/Vehicle/Pricing/PricingApiController.php
   - Problem: Declares `class PricingController extends Controller`.
   - Conflict: `PricingController.php` in the exact same directory and namespace also declares `class PricingController`.
   - Impact: Fatal error "Cannot declare class ... PricingController because the name is already in use".
   - Fix: Rename class to `PricingApiController` or delete `PricingApiController.php` if `PricingController.php` is canonical.

3. [MEDIUM] app/Models/Admin/DesignationDeptTree.php
   - Problem: Filename is `DesignationDeptTree.php`, but declared class is `class DesigDeptTree extends Model`.
   - Impact: Calling `App\Models\Admin\DesignationDeptTree` fails under PSR-4 autoloader.
   - Fix: Rename class to `DesignationDeptTree` or rename file to `DesigDeptTree.php`.

4. [MEDIUM] app/Models/Vehicle/Pricing/pricing.php
   - Problem: Filename has lowercase `pricing.php` while declared class is `class Pricing extends BaseModel`.
   - Impact: Linux/Docker filesystems fail case-sensitive PSR-4 class resolution.
   - Fix: Rename file to `Pricing.php`.

5. [MEDIUM] app/Models/Module/Booking/X_Vh_Stock.php
   - Problem: Filename is `X_Vh_Stock.php`, but declared class is `class XVehicleStock extends BaseModel`.
   - Impact: Calling `App\Models\Module\Booking\X_Vh_Stock` fails autoloading.
   - Fix: Rename file to `XVehicleStock.php` or rename class to `X_Vh_Stock`.

6. [MEDIUM] app/Models/Module/Booking/XlInsurer.php & app/Models/Module/Insurance/XlInsurer.php
   - Problem: Filename has uppercase `I` (`XlInsurer.php`), but declared class has lowercase `i` (`class Xlinsurer`).
   - Impact: Linux case-sensitive filesystems fail PSR-4 resolution when imported as `App\Models\Module\Booking\XlInsurer`.
   - Fix: Update class declaration to `class XlInsurer extends BaseModel`.
