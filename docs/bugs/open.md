# Bugs — open

Verified against the code and the local data on 29-09-2026 (each entry has a **Verified 29-09-2026** line).

**How this works (DEC-086):**
- `open.md` holds every bug that is not closed; `closed.md` every fixed / closed / won't-fix bug — with its **full
  details**, never deleted. Grep `### BUG-NNN` for an entry; `.ai/state/bugs-index.md` (generated by
  `php artisan ai:refresh-context`) lists the open ones for agents.
- **New bug:** the next free number (highest in either file + 1) → a row in the index + an entry at the end of
  `open.md`, immediately when found.
- **Fixed / closed:** set the row's Status (`FIXED …` / `CLOSED …` / `WON'T FIX …`) and Fixed date, add a
  `- **Fixed:** DD-MM-YYYY — what fixed it (commit, DEC)` line to the entry, then **move the row and the whole entry** to
  `closed.md` (keep the ids in order).
- **Changed information:** append a `- **Modified:** DD-MM-YYYY — …` line; never silently overwrite earlier findings.
- Entry format: `### BUG-NNN — title`, then Status, Severity, Found, (Modified), (Fixed), Where, Description,
  Proposed solution.
